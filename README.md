## 1. Visão Geral

Este repositório foi estruturado para armazenar os materiais de estudo, anotações e exercícios práticos desenvolvidos ao longo do **curso de JavaScript no SENAI**. Ele serve como um guia de referência contínuo e histórico do progresso de aprendizagem na linguagem.

---

## 2. Estrutura e Organização

- **Objetivo Principal:** Consolidação dos conceitos de lógica de programação e desenvolvimento front-end com JavaScript.
- **Arquitetura de Pastas:** O projeto encontra-se organizado em tópicos sequenciais (módulos/aulas), facilitando a localização de exercícios e conteúdos específicos.
- **Tecnologias Utilizadas:**
  - **JavaScript (ES6+):** Linguagem base para desenvolvimento da lógica.
  - **HTML5:** Estruturação das páginas web para teste dos scripts.
  - **CSS3:** Estilização básica e suporte visual para a manipulação do DOM.

---

## 3. Principais Conteúdos e Tópicos Abordados

1. **Fundamentos da Linguagem:**
   - Sintaxe e boas práticas.
   - Variáveis e escopo (`var`, `let`, `const`).
   - Tipos de dados (primitivos e complexos).

2. **Estruturas de Controle e Lógica:**
   - Operadores aritméticos, relacionais e lógicos.
   - Condicionais (`if`, `else if`, `else`, `switch`).
   - Laços de repetição (`for`, `while`, `do...while`).

3. **Funções e Manipulação do DOM:**
   - Declaração e invocação de funções (*Arrow Functions*, parâmetros e retorno).
   - Eventos de usuário (cliques, formulários, entradas de teclado).
   - Seleção e alteração dinâmica de elementos HTML e estilos CSS via JavaScript.
